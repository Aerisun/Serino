# 用户菜单文章权限卡设计

## 目标

让已获文章查看授权的登录访客，在用户菜单中快速看到自己的有效文章权限，并可进入列表后跳转阅读。

## 交互

- 仅当访客至少拥有一篇尚未过期、未撤销的文章权限时，用户菜单显示“拥有文章查看权限”卡片。
- 卡片显示可用文章数量，点击后打开独立弹窗。
- 弹窗逐项列出文章标题和剩余时间；标题使用省略号处理超长内容。
- 点击标题在新标签页打开对应文章详情，并保留当前页面状态。
- 列表容器随内容增长，最大高度约为视口的 60%；超过时只滚动弹窗内容区域。

## 数据与权限

- 新增登录态接口，只返回当前用户自己仍有效的文章授权。
- 单项包含文章标题、slug、到期时间与剩余秒数；不返回申请理由、审核记录或无效/撤销记录。
- 管理员沿用文章详情现有权限，不把无期限管理员访问权限混入这份个人授权清单。

## 实现边界

- 复用 Navbar 的日记权限查询、剩余时间格式化和 Motion 弹窗风格。
- 不改变文章申请、审批与授权流程。
